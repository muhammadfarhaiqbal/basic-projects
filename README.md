# Basic Projects — Muhammad Farhan Iqbal

Six beginner projects to practise web development, C++ and Python. Every project works on its own and has its own README with full instructions.

## Projects

| # | Project | What it is | How to run |
|---|---|---|---|
| 1 | [todo-list-app](todo-list-app/) | To-do list — add, complete, delete, filter, saved in localStorage | Open `todo-list-app/index.html` in a browser |
| 2 | [weather-app](weather-app/) | Weather app using the free Open-Meteo API (no key needed) | Open `weather-app/index.html` in a browser (needs internet) |
| 3 | [calculator](calculator/) | Calculator with keyboard support, safe evaluation (no `eval()`) | Open `calculator/index.html` in a browser |
| 4 | [student-management-system](student-management-system/) | C++ OOP: add/search/sort students, save & load from a file | `g++ -std=c++17 -Wall -o student-mgmt main.cpp && ./student-mgmt` |
| 5 | [atm-system](atm-system/) | C++ OOP: PIN login, deposit, withdraw, balance, mini statement (demo PIN 1234) | `g++ -std=c++17 -Wall -o atm main.cpp && ./atm` |
| 6 | [file-organizer](file-organizer/) | Python (stdlib only): sort a folder's files by type, with `--dry-run` preview | `python organizer.py <folder> --dry-run` then `python organizer.py <folder>` |

## Requirements
- Web apps: any modern browser
- C++ projects: `g++` (C++17)
- Python project: Python 3 (standard library only, nothing to install)
- Weather app: internet connection (free Open-Meteo API, no key)
