# To-Do List App

A simple to-do list in HTML, CSS and JavaScript. No build step, no framework.

## Features
- Add a task
- Mark a task complete (checkbox)
- Delete a task
- Filter: All / Active / Completed
- Clear all completed tasks
- Tasks are saved in the browser with `localStorage`, so they are still there after you close the tab

## How to run
Open `index.html` in any browser (double-click it, or drag it into the browser).

## Files
- `index.html` — page structure
- `style.css` — styling
- `app.js` — task logic + localStorage saving
