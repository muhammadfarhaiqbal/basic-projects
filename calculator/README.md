# Calculator

A calculator in HTML, CSS and JavaScript. No build step, no framework.

## Features
- Addition, subtraction, multiplication, division, modulo (%)
- Decimals
- Clear (C) and backspace (⌫)
- Full keyboard support: type numbers and operators, Enter for `=`, Esc to clear
- Division by zero shows `Error` instead of crashing
- **No `eval()`** — calculations are done with a safe manual evaluator, so no code can be injected through the input

## How to run
Open `index.html` in any browser (double-click it, or drag it into the browser).

## Files
- `index.html` — page structure
- `style.css` — styling
- `app.js` — calculator logic (safe manual evaluation)
